# 《金书江湖2》V0.94B 系统拆解

> 分析对象：`金书江湖2V94B-绿色完整版`（RPG Maker XP / RGSS103J，更新至 094B）
> 方法：解包 `Data/Scripts.rxdata` 得到 221 个 Ruby 脚本（约 245 万字符），解析 `GameData.rxdata` 的数据表与 `MapInfos.rxdata`，并通读两份官方说明文档。四位分析员分别复核了战斗、养成、门派经营、江湖/周目四条线，逐行结论见文末附录。文中无法确认的地方标“未确认”。

## 二、核心循环

```
月初：分配每名弟子的 1 次行动
      ├─ 修炼（内功/外功/身法）→ 熟练度 + 人物经验
      ├─ 生产/打工（药田、矿场、伐木、织布、猎坊、市集）→ 材料 + 银两 + 建筑经验
      ├─ 探索/拜访（大地图）→ 结识散人、声望、好感、情报
      └─ 研究/传功（经阁、演武场）→ 研究点、弟子经验
                ↓
      结算：银两、材料、研究点、声望、门派好感、武学进度
                ↓
      消费：升级建筑 → 解锁专精树/配方/招募位
            学武/升级武学 → 战力提升
            铸造/织造/合成 → 装备
            招募弟子 → 填充 9 个门派职位
                ↓
月末：地图事件 / 可视图标遭遇 / 踢馆 / 副本 / 会武 / 神秘势力入侵
                ↓
      通关（统一江湖/灭派/主线）→ 传承 → 周目 +1
```

关键点：**时间不是背景，而是最稀缺的资源**。每名弟子每回合只能行动一次（V049 起明确“已行动弟子轮空”），修炼、生产、探索、研究都在抢这一次行动。玩家每个月都在做“练功还是赚钱/找人/升建筑”的取舍。

## 三、时间、地图与遭遇

- 时间粒度：**年 / 月 / 旬**，`play_turn = day + 4*month + 48*year - 52`（`190_[玄]地块管理.rb:357`），即**每月 4 回合、每年 48 回合**。
- 脚步不消耗时间；时间是**行动资源**，只在弟子行动/事件推进时消耗。
- 自动存档：每月一次（更新纪要 V043）。
- 大地图：江南、中原、西南、西域、关外五张区域图并列，切换区域不耗时（`153_Scene_Main_Map.rb:122-176`）；西域、关外未完全开放。
- **遭遇不是踩地雷**，而是每月重掷 9 个“可视图标槽”（3 区域 × 3 槽，`002_Game_System.rb:153-178`）：
  - 马贼 261-263 只在江南；魔教 264-266 在中原/西南；镖车 268-270 通用；番僧 275 只在西南；
  - 无名 273 / 雄霸 276 仅在仍是隐者时入池；
  - 每月 25% 概率用一个 Boss 顶替普通槽。
  - 玩家能在大地图上看见本月会刷什么，从而规划路线——这是比随机遇敌高级得多的信息设计。
- 难度不靠选项，而靠**周目**：敌人每周目 +15 攻 / +20 伤害 / +8 命中，玩家对其破甲 -10（`011:73-91`）；玩家承受的伤害再用开方级曲线压缩，系数随周目从 75% 降到 15%（`010:1337-1340`、`2175-2190`）。
- “45 回合门派被袭击”“两年期限”等说法来自文档/更新纪要，脚本层未确认；可确认的是周目加成与敌方无限增长事件。

## 四、门派经营：真正的核心系统

### 4.1 地块与建筑

门派由**生产地 4 + 内门 4 + 荒地 1 + 正殿 + 经阁**共 11 块地组成；山门地契（嵩山别院/武夷山/通元谷）会额外增加地块与特产（`190:1-31`，变量 202/204）。

| 地块类型 | 可建建筑 | 建造价格 |
| --- | --- | --- |
| 外门（10 种） | 打铁铺、伐木场、药田、织布坊、猎坊 | 500 两 |
| 外门（10 种） | 铸造房、织造房、炼丹房、市集、厨房 | 1,500 两 |
| 内门（8 种） | 演武场 | 500 两 |
| 内门（8 种） | 冥想室、兵器场、武馆 | 2,500 两（需先有演武场） |
| 内门（8 种） | 决刃堂（刀）、御剑阁（剑）、野拳门（拳）、枪皇阁（枪） | 5,000 两（需武馆类） |

- **建筑等级** 1–7，按累计产量经验升级：`0/181/721/1981/4501/8281/13321`（`190:667`）。
- 生产建筑每回合产出 `1 + 等级/2` 个基础材料；等级越高，稀有产物概率越高。主产物：铁矿石（100 两）、木材（50）、草药（50）、棉线（50）、食材（50）；稀有：玄铁（10000）、乌木（10000）、人参（4000）。
- 稀有判定是**确定性伪随机**：`(地块ID + 年 + 月 + 2×日) % 等级`（`190:388`）——读起来像随机，实际可按月历预测，方便玩家规划。
- 关键建筑效果：
  - **正殿**：香火例钱上限 `1200 + 800×等级`；每回合例钱 `min((2500+声望)/5.5, 上限)`，再乘 `(100 + 市集加成 + 掌柜加成)%`，有职位技能时 ×1.3（`190:1006-1044`）。
  - **经阁**：每回合研究点 = `(100×经阁等级 + 4 + 8×成名数 + 12×绝学数 + 20×奥义数 + 加成) × (100+正殿等级)/100`（`190:1045-1059`）——**收藏的武学品阶越高，研究点越多**，形成“收集→研究→学更多”的循环。
  - **演武场**：修炼经验加成 `100×等级`（`190:653`）。
  - **市集**：香火加成 `8 + 2×等级` %（`190:649`）。
  - **酒馆**：按门派声望刷新可招募侠客；声望越高，高品质人物概率越高。
- 建筑价格存在一个可复现缺陷：千两级建筑只判 `gold < 500`，可能把银两扣成负数（`191:205` 等）。

### 4.2 九个门派职位（最值得借鉴的设计）

门派可任命 9 个职位，每个职位绑定一名弟子，并按该弟子的能力提供**全局加成**（`155_Window_Position.rb:131-172`）：

| 职位 | 效果 | 数值来源 |
| --- | --- | --- |
| 掌门 | 每回合声望、全弟子武学威力 | 战力/40 |
| 副掌门 | 战斗威力 | 战力相关 |
| 传功长老 | 弟子修炼经验 | 属性相关 |
| 研武长老 | 每回合研究点 | 属性相关 |
| 执法长老 | 自身武学威力 | 属性相关 |
| 总管 | 生产经验基数 | 属性相关 |
| 掌柜 | 香火/金钱收益 | 等级/3 % |
| 知事 | 大地图工作收益 | 属性相关 |
| 知客 | 声望收益 | 战力/60 |

每个职位还对应一个“职位技能”（`pos_skills`），例如掌柜的 `557` 让香火 ×1.3、研武的 `607` 让研究点 ×1.25；加成数值由被任命弟子的属性实时计算（变量 166–175）。

**设计价值**：它把“上阵角色”和“后勤角色”统一了。一个战斗力不强但属性合适的弟子可以当掌柜/总管，仍然有存在感，避免“板凳队员”问题；同时迫使玩家在“让谁上阵”和“让谁当官”之间做取舍。弟子默认出战 7 人（`157:11`）。

### 4.3 经济、物价与声望

- **香火**：见 4.1；分宗贡银 = `0.096 × 被征服门派所有人的战力之和`（`190:1062-1076`），索贡上限 5,000 两/次（`209:450`）。
- **物价**：`na_para × 系数 × price / 100000`，`na_para` 每月 `800 + rand(351)`（`190:307`）；卖出默认一折（`209:102`）；买入门派店 +50%；**征服门派后买入系数为 0（免费）**（`209:179`）。
- **声望的真正作用**：除了香火/拜访门槛，它还**钉死散人等级上限**——各声望档位（1500/4000/8000/15000/25000/39000）把散人等级上限分别压在 **25/36/49/63/78/90/99**（`002:412-427`）。也就是说，“刷声望”不是刷一个抽象分数，而是直接决定你能招到多强的人。
- **善恶**：只影响两把武器（浩然正气 +善恶、凶邪煞气 +(-善恶)，均 ≤400）的威力（`011:1387-1407`）；94B 中门派结交的善恶门槛已被注释，实际只卡声望。

### 4.4 门派互动：并派、灭派、分宗

- **结交门槛**：`need_fame = 6.5 × 目标等级²`，映射到 7 档名望（1500/4000/8000/15000/25000/39000/52000，`195:1110-1138`）。
- **并派**：置 `switches[100+id]`、把目标门派加入 `defeat_class`、部分人物转“隐居/散人”、其余转“分宗”；分宗好感锁 999，每回合进贡，可索取贡品与武功（`195:866-948`）。并派条件函数在 94B 已被掏空为恒真（`195:2146`）。
- **灭派**：全员转 class 40（死亡）永久消失（`195:1636-1658`）。
- **请教**：好感达到门槛后可向 NPC 学武；门槛随品阶提高（约 50/80/100），指点收益与 NPC 战力、双方等级差有关。
- **助战**：好感足够可请 NPC 助战，消耗与其等级相关（≤20 级免费）。

这套“声望—好感—并派/灭派”的三轴设计，把线性武侠故事变成了可反复经营的地缘沙盘。

## 五、弟子与养成

### 5.1 品质与属性

- 品质六档：**神 / 天 / 地 / 玄 / 黄 / 凡**，对应 **金 / 橙 / 紫 / 蓝 / 绿 / 白**（V061）。
- 基础属性：HP、SP（真气）、力量、灵巧、身法、内力，以及命中/回避/攻/防等派生值（`020:493-633`）。
- 等级上限与经验曲线未确认；可确认 70 级可学奥义、武学等级 ≤ 人物等级/10。

### 5.2 武学“三槽”装备（关键机制）

每名角色同时只装备**三门外功/内功/特技（身法）**（`@sid / @nid / @tid`），只有装备中的武学才把 `power × 等级` 计入属性（`020:639-659`）。战力评价（`ce`）也一样：

- 内功/身法/特技只算当前装备的那一门；
- 外功只取所有外功中**最高的一门**；
- 天赋按 `power` 求和。

所以“堆学大量武功”既不加属性也不加战力（V045 明文），玩家必须围绕“当前三槽”做搭配。这是金书江湖最聪明的反膨胀设计之一。

### 5.3 熟练度与请教

- 每门武学 0–10 级（`LEVEL_LIMIT=10`，`212:50`）。
- 第 n 级累计消耗 = `price × n(n+1)/2`，`price` 藏在技能描述的 `@` 后（`212:189-213`、`164:338`）。
- 每级威力 +16%；SP 消耗 ×(1 + 0.2×等级)（`212:540`）——等级越高越贵，逼玩家做取舍。
- 满 10 级可“撰写”入经阁，换声望 `price/2.5`（`166:68-88`）。
- 来源：战斗出招 `(lv/1.5)+20+rand(10)`（`123:330`）、挂机修炼、演武加速、传功长老、请教、丹药（受药抗递减）。
- 请教门槛：好感约 50/80/100 对应成名/绝学/奥义。

### 5.4 天赋

两套独立系统：

**A. 人物天赋**（技能 500–700 号，`element 4`）：
- 天赋点：普通主角 `400 + 80×周目`；部分定制角色使用专属公式（160~320 + 80×周目，个别角色甚至是从负值起步，`161:17-41`）。
- 花费 = 该天赋的 `power`；最多同时携带 **5 项**；掌门/职位天赋互斥。
- 获取：开局自选、石刻（低/中/高三级，四选一，高级不再出低级）、天赋书、剧情/专属。
- 效果从“+命中”到“改变战斗规则”（剑道神话、二天一刃、江湖聚贤等）。

**B. 门派建筑天赋树**（`pskill_level`，6 建筑 × 7 项）：
- 见 5.5；等级上限 7，且 **≤ 对应建筑等级**（`215:474-483`）。

### 5.5 六棵专精树（建筑等级绑定）

| 树 | 7 级效果 | 升级费用（研究点） |
| --- | --- | --- |
| 冥想室 | 内功/特技熟练、研究点转化、护体率、加力率、内力转集气、减伤 | 100 / 250 / 500 / 1250 / 2750 / 8500 / 9000 |
| 兵器场 | 外功/身法熟练、研究点、身法加力、出招率、招式转集气、全武功威力/重击 | 125 / 225 / 560 / 1480 / 3050 / 7200 / 9200 |
| 刀/剑/拳/枪阁（各一棵） | 本系熟练 +150/级、命中/出招/伤害/重击各 +1%/级、受本系伤害 -3%/级、经阁每收录一本本系武学威力 +3.33/级 | 500 / 3120×4 / 4250 / 5050 |

**硬约束**：专精等级 ≤ 对应建筑等级；武学等级 ≤ 经阁等级（`213:31,348,383`）。两条规则把“经营”与“战斗成长”锁死在一起——想变强，先升建筑/升经阁。

## 六、武学体系

### 6.1 品阶与门槛

- 品阶不是独立字段，而是技能 `element_set` 里的属性 ID：**基础 12 / 成名 13 / 绝学 14 / 奥义 15**（`011:2470-2477`）。
- 品阶影响：
  - 出招率：对 `rand(500)` 分别加 `+200 / +100 / 0 / -50`（`011:2470-2483`）；
  - 战力系数：内/身/特 `9/18/37/57`，外功 `6/12/25/38`（`195:557-627`）；
  - 学习门槛：人物 20 / 50 / 70 级（`217:647-656`）；
  - 请教好感：约 50 / 80 / 100。
- 学习条件（`217:633-2012`）是逐门硬编码的，典型组合：
  - 前置武学 + 前置等级：玄铁剑法需“海潮内劲 8 级”；求败剑意需“玄铁剑法 10 级”。
  - 属性门槛：枯荣禅功需内力 80 + HP 4000 + SP 3500；海潮内劲需内力 360 + HP 5000。
  - 经阁等级：武学等级不得超过经阁等级。
- 学习货币：**武学研究点**（经阁产出），费用按技能等级递增；`xuan_skill_judge` 返回“习得条件已达成”才允许购买。

### 6.2 战斗中的四种触发

1. **出招（招式）**：外功按概率触发招式特效（伤害倍率/附加状态/范围变化）。
2. **加力**：内功按概率把真气转化为额外伤害或特效。
3. **护体**：内功按概率减伤/免疫/反击；不同内功有完全不同的护体脚本（`010:608-986` 有 30+ 种）。
4. **重击**：暴击，概率来自灵巧与天赋，倍率 1.35。

### 6.3 “例外即内容”

`010_Game_Battler 3◎.rb` 里有成百上千条“某武学/某天赋/某装备 ID → 特殊效果”的硬编码：金蝉脱壳 40% 免伤、一法一尊伤害强制为 1、麒麟魔体免伤、藏锋剑意半血免伤……这是金书江湖最重要的“爽点”来源：**每一本绝世武学都有一条别人没有的规则**。代价是平衡与维护成本极高（见第十二节）。

## 七、战斗系统：网格 + 集气条（CTB）

### 7.1 行动条

- 战场是 32px 网格，四方向 BFS 寻路，移动范围上限 20 格，**无高低差**（`128`、`127`）。
- 每场战斗开始时，`slg_base_cp = min(400, 全场最高身法)`（`115:386`）；每个战斗者初始延迟 100（`008:89`）。
- 每帧集气：`cp += 身法 × 400 / base_cp`，另有最多 12 类修正（赤绝 +20%、巽风 2 件 +10%、破釜沉舟按损血加身法、千秋大劫、天罡北斗、侠隐阁、光明圣火、众志破虏、内修/外修专精等，`120:59-144`）。
- `cp ≥ 100` 时，每 100 点让 `delay_time -1`；`delay_time ≤ 0` 时行动，行动后 `delay_time += base_cp`，再加 `action_delay + motion_delay`，封顶 420（`123:895-898`）。
- **半回合 = 25 帧**，整回合 = `50 × 400 / base_cp` 帧（`120:24-26`）；状态、DOT、冲穴都按半回合结算。
- 封穴、睡眠、笑毒状态下**不集气**（`120:59`）。

> 这是“以全场最快单位为标尺”的归一化 CTB：身法差距体现为行动频率差距，但不会因为数值膨胀而出现“一回合动十次”。比单纯的速度排序更有策略深度，也比纯 ATB 更可控。

### 7.2 伤害公式（简化）

普通攻击在实战中已被移除（`122:176-192` 注释掉），几乎所有伤害走 `skill_effect`：

```
rate  = 50 + 力量×str_f/100 + 灵巧×dex_f/100 + 身法×agi_f/100 + 内力×int_f/100
power = (技能威力 + 攻击×atk_f/120) × rate/100 + 固定加成
power -= 目标防御 × pdef_f/200（穿透按比率封顶）
攻防差 d = 1.95×攻击 - (防御 - 穿透)
按 d 所在区间做 8 段平滑修正（-35% ~ +35% 倍率 + 线性加减）
伤害 = power × 修正 × 属性克制 × 重击(1.35) × 格挡(0.5)
```

关键行：`010:1266-1373`。此外还有一层 `unline` 台阶压缩：敌人按武学档次取 `120/125/105/85/68`，玩家随周目从 75 降到 15（`010:1336-1348`、`2175`），用于压制数值爆炸。

- 命中：`rand(100) < 技能命中 + 修正`，`atk_f>0` 时再乘 `user.hit/100`（`010:1255-1260`）。
- 闪避：`100 + 命中修正 - 回避×eva_f/100`（`010:1400-1403`）。
- 重击：`rand(100) < 灵巧/16 + 天赋加成`，只 ×1.35（`010:1371`）。
- 护体/加力共用一条曲线：`rand(600) < min(内力, 550)`，即约 `内力/600` 的概率（`010:989-1016`、`011:5682`）。破气状态归零，霸体免疫杀气。
- 反伤：`re_mul% × (伤害 + 追加伤害)`，封顶 `1400 + rand(200)`（`010:1606`），没有独立反击动作。
- SP 消耗：`spcost × (100-var138)/100 × (1 + 0.2×等级)`（`010` / `212`）。
- 药抗：0–99，配合状态 20/23/24 把回复压到 70%/40%/10%。
- 冷却表存在但递减与写入都被注释，**实际未启用**；没有通用连击，只有“左右互搏”等个别 proc。

## 八、装备与制造

### 8.1 随机装备：母本 + 前缀 + 后缀

`207_随机装备.核心.rb` 实现了一套完整的 Diablo 式词缀系统：

- 每件装备 = **母本**（基础武器/防具）+ **前缀** + **后缀**（武器前缀 507–530、防具 511–529，后缀 531–558/531–565）。
- 前后缀各自带“品质”，品质有权重：`198:+6、201:-1、202:0、203:+1、204:+2、205:+4、206:+6`（`207:320`）。
- 装备总品质 = 前后缀权重之和，决定颜色：白 / 绿 / 蓝（2–3）/ 紫（4–5）/ 橙（6–7）/ 金（8–11）/ 红（12+）（`207:242`）。
- 数值叠加两种模式：带 `199` 属性则“加法叠基准值”，否则“乘法百分比”（`207:563`）；`VARY_DATA_TIMES=0`，所以没有额外随机浮动。
- 前后缀还能附带自动状态、动画、图标；`create_item(...)` 支持指定品质/强制前后缀，便于剧情奖励与商店。
- 同一母本已有某品质时，不会再附加同品质前后缀。

### 8.2 制造链

- 铸造（武器）/ 织造（防具）分开，建筑等级解锁配方；配方由“图纸 + 建筑等级”双门槛控制。
- 一次制造：物品产 100 个，装备产 1 件；铸造/织造使用**预摇 100 条订单队列**（`002:464-589`），神匠天赋 504 切更好池（`194:1817`）。
- 高等级建筑造低阶物品时，经验按 `100/50/25/10/5/2/1` 衰减（`194:1556`），防止刷低级配方。
- 天赋【神匠铸造】/【神匠织造】提升品质并可能出特殊属性（V091A）。
- 套装：少量套装，集齐给额外效果（V080）。
- 材料：生产地块、商店、副本、采集；高级配方需要“命名材料”（云纹叶、赤阳砂等），与药谱/矿谱收藏共用。

## 十一、实现特征（为什么它看起来“什么都有”）

1. **全局变量即状态**：300 个开关 + 500 个变量，名字直接写明用途（`门派声望`、`善恶度`、`正殿Level`、`内门地块1类型`……）。好处是事件系统可以直接读写；坏处是存档迁移、调试、多人协作都极其痛苦。
2. **事件驱动 + 脚本兜底**：301 条公共事件承担剧情、门派、副本流程；Ruby 脚本只负责规则与界面。这让作者（一个人）能快速堆内容，但逻辑分散。
3. **硬编码例外**：大量 `if skill_id == xxx` / `if actor_id == xxx`。这是“一个人的内容型游戏”的典型做法：用最短路径实现独特效果，代价是平衡与维护。
4. **UI 堆叠**：RMXP 默认 640×480，作者用大量图片、窗口、鼠标脚本硬堆出复杂界面；更新纪要里“闪退/卡顿”修复占了相当大的篇幅。
5. **数据即内容**：400 敌人、999 物品、600 武器、415 状态，很多是换皮/换名；真正独特的是几十本绝学、几十个天赋、几十个事件。

### 12.2 具体设计建议

**（1）门派职位：把“板凳角色”变成资产**

- 岗位：传功长老（训练经验 +X%）、研武长老（研究点 +X/周）、总管（采集/生产 +X%）、掌柜（银两收入 +X%）、知客（声望/好感 +X）。
- 数值：`加成 = 基础值 + 该角色对应属性 / 系数`，让不同角色适合不同岗位。
- 反馈：职位界面直接显示“本周预计收益”，让玩家每月调整一次。
- 接口：`GameState` 里加 `sect.posts` 字典，训练/采集/结算时读取；存档迁移给默认空位。

**（2）四系天赋树：让门派建设“反哺战斗”**

- 每座建筑对应一棵 7 级树（例如藏经阁→研究/武学威力，演武场→训练/出招，药圃→丹药/回复，锻造坊→装备/暴击）。
- 升级消耗“研究点”，研究点由藏经阁按周产出；专精等级不能超过建筑等级。
- 这样玩家在“升建筑”与“造装备/学武”之间自然产生取舍，而不是把建筑当成一次性解锁。

**（3）武学三槽：把“收集”变成“搭配”**

- 现有武学列表加 `equipped` 标记，只允许 3 门同时生效（外功/内功/轻功）。
- 属性加成 = `武学基础加成 × (1 + 等级×0.1)`；界面显示“当前生效”。
- 好处：解决“学得越多越强”的线性膨胀，让每本新武学都要和现有三槽竞争。

**（4）随机装备词缀：延长锻造寿命**

- 词缀池按品质分档（白/绿/蓝/紫/橙/红），每个词缀有 weight；总权重决定颜色。
- 词缀效果用数据驱动（`{stat, mode: flat|percent, value}`），不要写死 `if weapon_id ==`。
- 与现有“专精/流派”联动：例如“剑系词缀”只出在剑上，鼓励围绕流派刷装备。

**（5）江湖声望与门派好感：把线性章节变成可探索的江湖**

- 你们已有自由探索和地区委托，只需加两个计数器：`jianghu_fame`、`sect_affinity[sect_id]`。
- 委托 +声望；帮助某门派 +好感；好感达到阈值解锁“请教武学/购买特产/借用弟子”。
- 金书最值得学的一点：**声望不仅加数值，还决定你能招到的人的上限**。你们可以把“声望”接到弟子/同伴招募的品质上。
- 不要做“并派/灭派”这种大系统——你们的主线是六章叙事，做轻量“门派关系”即可。

**（6）周目继承：提高长线留存**

- 通关后保留：图鉴、成就、药谱/矿谱、1 件传家宝（装备）、若干银两；
- 新周目敌人 +10%~15%，可选“跳过已看过的剧情”；
- 给一个“周目专属”的隐藏 Boss 或结局碎片，给重玩一个叙事理由。

### 12.3 不要抄的部分

1. **不要一次做 50 个门派、400 个敌人、1000 个物品**。金书是 10 年、94 个版本堆出来的；你们的团队和周期不允许。内容的“密度”比“数量”重要。
2. **不要用硬编码例外做平衡**。金书有几百条 `if skill_id ==`，导致后期每次改动都可能引入新 Bug（更新纪要里大量“修正某某武学”）。用数据表 + 效果 DSL（`effect: {type: "damage", ...}`）来扩展。
3. **不要让付费/VIP 解锁人物影响单机平衡**。金书的 VIP 全解锁是商业模式，不是设计优点；你们走 Steam 买断，应保持“所有内容可玩到”。
4. **不要照搬它的 UI 堆叠**。RMXP 的窗口/图片堆叠是时代限制；Godot 的 Control 节点 + 主题系统可以做得更干净。
5. **不要用全局变量当存档**。你们已经有版本化存档与迁移，继续坚持；新增系统时先设计 schema 再写逻辑。

### 12.4 三阶段路线（建议）

**阶段一（2–3 周，低风险）**
- 门派职位 4–6 个（传功/研武/总管/掌柜/知客），接入训练、研究、采集、银两、声望。
- 江湖声望 + 门派好感两个计数器，接入现有委托与商店折扣。
- 四座建筑等级 gate 现有专精境界（专精等级 ≤ 建筑等级）。

**阶段二（1–2 个月，中风险）**
- 武学三槽 + 熟练度属性加成。
- 随机装备前后缀（先做 20–30 个词缀，覆盖四系）。
- 门派委托板：每周 2–3 个随机委托（送药/清剿/拜访），给声望与材料。

**阶段三（版本级，长期）**
- 周目继承 + 隐藏 Boss。
- 门派关系事件链（帮助/竞争/联姻），但不做并派/灭派。
- 可选副玩法（例如“门派大比”自动战斗），复用现有战斗 AI。

---

## 十三、一句话总结

金书江湖2 的核心不是“战斗做得多好”或“剧情多强”，而是**用极低成本把“经营—养成—战斗—江湖—周目”串成了一个每回合都有事可做、每次重开都有新目标的循环**。对《山河问道》最有价值的三件事是：**门派职位（让每个角色有用）、建筑 gate 专精（让经营反哺战斗）、武学三槽（让收集变成搭配）**。这三件事都不需要推翻现有架构，却能显著提高“每回合的决策密度”。
