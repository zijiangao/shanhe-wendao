# 完整版难度与养成调整报告：0.165.0

日期：2026-09-28。结论：**适度养成路线已通过定向规则验收；标准难度不再被裸装普攻路线轻易打穿，准备路线仍保持紧凑。**

## 本轮目标

根据上一轮报告的 P1/P2 问题，保留自由旅行和两年期限，不用强制等待凑周数。章节战斗需要有意义的准备，但玩家可以选择修炼、购买装备，或采集锻造；休闲难度允许用资源换时间。

## 调整内容

- 华山试炼改为固定章节挑战：两名敌人的生命、攻击和速度提高到独立的章节基准，目标为撑过五轮或击败全部对手。
- 终战改为固定章节挑战：保留弩手、玄甲亲卫与两阶段首领的分工，强化首领与前排威胁；苏晚晴路线仍会削弱弩手，但不会移除远程威胁。
- 章节数值只在新战斗创建时应用。已有战斗、自动存档和战败重试继续使用原敌方数值，不会因更新或读档被重新平衡。
- 商店新增高价百炼龙泉（攻击+5）和百炼护心甲（防御+4），价格分别为3500和4000两；它们与采集锻造的顶级装备同档，提供花钱省时间的路线，原有商品价格保持不变。
- 华山对话和任务日志说明五轮目标、护甲和回春散；终战日志提示先处理弩手、注意首领横扫，并说明可以自由回程整备。
- 菜单版本与 Windows Desktop 预设同步为 0.165.0；Demo 预设与构建未改动。

## 定向结果

测试工程 `ShanheWendao-iteration-tests` 中运行 45 条流程：休闲/标准/宗师 × 裸装赶路、商店路线、均衡准备、周任务修炼、采集锻造 × 3 个随机种子。

| 路线 | 结果 |
| --- | --- |
| 标准/宗师：均衡准备、修炼、采集锻造 | 每组 3/3 完成，通常第 13–14 周通关 |
| 休闲：商店路线 | 3/3 完成，第 3–4 周通关 |
| 标准：裸装、只用普攻 | 0/3 完成，终战不再被无准备路线稳定打穿 |
| 裸装赶路：三档难度 | 均在华山或终战失败，说明章节准备有实际作用 |

均衡标准路线的示例战斗从第1周黑苇渡、第6周华山到第13–14周终战；终战起始气血约69–78，使用约1–2份回春散后完成。宗师均衡路线仍能完成，但终战通常使用约10份药并保留较少余量，压力明显高于标准。定向脚本记录在本机忽略目录 `build/balance-0165/`。
