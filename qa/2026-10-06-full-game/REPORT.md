# 《山河问道》完整版 0.168.0 验收记录

日期：2026-10-06。基线提交：`698358737fac17c41b2c136999b6ee18343e6e13`。

## 结论与范围

完整版的主线、战斗、养成、门派建设和存读档自动化验收通过，Windows 正式导出包已更新到 0.168.0。本次修复了实际发现的界面和建设收益问题。Demo 未修改、未导出、未运行验收。

本记录包括规则驱动的完整旅程、渲染测试和部分真实桌面操作。它不能代替真人从头到尾游玩，也不能证明实际游玩分钟数、趣味性、低配表现或 Steam 实机兼容性。当前适合进入玩家体验测试，尚不能据此判定已满足全部上架条件。

## 修复内容

- 青云门的门派建设入口移开了目标说明卡，入口与当前任务均可读。
- 设置与键位设置页根据可用高度滚动；返回按钮固定在滚动区域外。键盘焦点能将底部操作滚入视野，100%、115%、130% 的测试均覆盖实际返回行为。
- 抉择页根据可用高度布局并跟随焦点滚动，门派、商店和剧情的末项操作在放大后仍可到达。
- 沈羽分派任务中的修炼结算现在收到演武场的额外经验，基础属性奖励仍只发放一次。侠客原有修炼经验不受影响。
- 打造说明分别显示挖矿专精与门派建设的实际减免，减免合计以剩余矿石成本为限。
- 商店文案中的“移动消耗周数”已纠正：移动不消耗周数，每周进行一次行动，主动结束本周后结算。
- 菜单内的制作名单版本、Windows Desktop 的文件版本与产品版本同步为 0.168.0 / 0.168.0.0。

## 流程与数值观察

准备路线使用实际训练、购买、打造与战斗逻辑，训练成绩和战斗输入由脚本提供。三种准备方式（均衡、训练、打造）× 三种难度 × 三个随机种子，共 27 / 27 条路线通关，结束在第 13–14 周。仅购买高级装备的快速路线在休闲难度 3 / 3 通关，标准与宗师均为 0 / 3。缺乏准备的快速主线样本说明玩家仍需要按章节提示进行养成；这属于观察到的规则结果，不是脚本执行失败。本次没有调整经济或敌人数值。

门派专项旅程在标准难度下比较了不建设与四项全部升至 3 级。该路线为检查建设、收益、训练和打造而安排额外行动，不代表普通玩家的最短或平均流程。

## 已知限制与诊断归属

- 130%、1280×720 窗口下，顶部状态栏右侧及主菜单底部仍有裁切，见放大截图；本次设置、键位与抉择页返回操作已修复，顶部栏和主菜单的整体适配仍待处理。
- 尚待真人完整游玩，记录实际耗时、重复劳动、章节提示是否充分和结局体验；尚待低配机器、手柄与 Steam Deck 实机验证。
- Steam 检查只验证本地发行数据与离线逻辑，未验证真实账户、云同步、成就上传或覆盖层。
- 沙箱环境出现系统证书存储读取失败。原始日志保留这一诊断，检查结果只排除此条已知环境错误，不排除其他脚本、断言或引擎错误。
- 损坏/未来版本存档与无焦点控件测试有预期拒绝诊断；暂停截图测试退出时出现 ObjectDB 残留警告。当前证据不足以把测试退出警告认定为游戏运行时泄漏，仍保留日志以便复查。
- 初次资产导入先于字体缓存就绪、早期 UI 探针未设置独立 APPDATA、无窗口截图等待以及导出 EXE 不支持外部测试脚本，都曾导致验收工具失败。包版本探针最初只查看主菜单而未打开制作名单，也曾失败。相应尝试已保留；修正后成功结果与这些失败尝试分别记录，没有当作产品通过证据。
- 最终留白补验的初始日志扫描把环境诊断中的 `Failed` 误当为测试失败。六个进程均正常退出，原始日志及初次分类保留；明确排除证书诊断后重新核对为 6 / 6。
