# Project workflow

- After completing changes and relevant validation, commit and push them to the configured remote, as requested by the user. Keep unrelated local files out of the commit.
- Focus on the full game only. Defer demo work until the user says the full game is ready.
- When exporting a new full-game version, update the menu version and Windows Desktop export preset together. Export and verify only the full game; leave the demo preset and build untouched.
